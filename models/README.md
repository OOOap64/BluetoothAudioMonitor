# Модель звуков

Файл `sound_model.npz` — обученный классификатор для определения источника
звука. Он используется приложением автоматически, если лежит в этой папке
(путь можно переопределить переменной `BLUETOOTH_MONITOR_SOUND_MODEL`).

## Классы

- `speech` — речь;
- `yelling` — крик, эмоционально громкая речь;
- `bird_singing` — пение птиц, крики птиц;
- `door_opening` — стук и скрип двери;
- `fire_burning` — треск огня, взрывы/фейерверки;
- `noise` — дождь, ветер, волны, техника, транспорт и другой фон.

## Метрики

Модель обучена 12.11.2026 на 1680 записях. Проверка — 20% записей,
стратифицированно по классам.

| Класс | Precision | Recall | F1 | Примеров |
|---|---:|---:|---:|---:|
| speech | 0.92 | 0.87 | 0.90 | 134 |
| yelling | 0.73 | 0.81 | 0.77 | 58 |
| bird_singing | 0.87 | 0.83 | 0.85 | 24 |
| door_opening | 0.72 | 0.81 | 0.76 | 16 |
| fire_burning | 0.62 | 0.81 | 0.70 | 16 |
| noise | 0.92 | 0.86 | 0.89 | 88 |

Итоговая точность на проверке — **85,12%**, на обучении — 95,05%.
Полный отчёт: `sound_model_report.json`.

Это базовая модель, а не замена записям из ваших условий. Для конкретного
микрофона, комнаты, языка и набора событий качество будет выше после
переобучения на собственных данных.

## Данные

- **ESC-50** (Piczak, 2015) — 720 записей из классов `chirping_birds`,
  `rooster`, `crow`, `door_wood_knock`, `door_wood_creaks`, `crackling_fire`,
  `fireworks`, `rain`, `wind`, `sea_waves`, `thunderstorm`,
  `vacuum_cleaner`, `washing_machine`, `clock_tick`, `helicopter`, `engine`,
  `airplane`, `train`.
- **RAVDESS** (Livingstone & Russo, 2018) — 960 записей эмоциональной речи:
  нейтральная, спокойная, радостная и грустная — класс `speech`; сильные
  злость, страх и удивление — класс `yelling`.

Лицензии: ESC-50 — CC BY-NC 3.0, RAVDESS — CC BY-NC-SA 4.0. Модель является
производной от этих данных; учитывайте некоммерческие ограничения и
указывайте источники при распространении.

## Переобучение

```bash
python tools/train_sound_model.py \
  --dataset data/sound_dataset \
  --output models/sound_model.npz \
  --epochs 400 \
  --report models/sound_model_report.json
```

Структура датасета и требования к записям описаны в
`docs/SOUND_TRAINING.md`. Кнопки обучения в интерфейсе нет — только CLI.
